랜덤포레스트 회귀 모델 기반 변수 중요도 비교 (MDI vs Permutation)
1. 분석 개요
본 보고서는 2024년 노트북 가격에 영향을 미치는 핵심 요소를 규명하기 위해 랜덤포레스트 회귀 모델을 적용한 결과를 다룬다. 변수의 상대적 중요도를 두 가지 관점(MDI, Permutation)에서 측정하고, 두 지표 간 순위 변화를 통해 가격 결정 구조의 실질적 특성을 도출하였다.

2. MDI와 Permutation 방식의 기술적 차이
두 지표는 산출 원리가 근본적으로 상이하며, 이로 인해 순위 해석의 신뢰도에도 차이가 발생한다.

MDI (Mean Decrease in Impurity, 불순도 감소 기반)

트리 분기 과정에서 각 변수가 불순도(오차)를 얼마나 감소시켰는지를 학습 데이터 내부에서 집계한 값이다.
연산이 빠르나, 학습 데이터에 의존하므로 과적합 편향에 취약하다.
특히 고유값(cardinality)이 많은 연속형·범주형 변수(예: Processor, GPU)의 중요도를 구조적으로 과대평가하는 경향이 있다.
Permutation (순열 중요도 기반)

특정 변수의 값을 무작위로 섞어 예측 성능이 얼마나 저하되는지를 측정한다.
실제 예측력을 반영하며, 검증 데이터에서도 적용 가능해 일반화 성능에 더 근접한 지표로 평가된다.
결론적으로, MDI가 '모델이 얼마나 자주 참조했는가'를 나타낸다면, Permutation은 '실제 가격 예측에 얼마나 기여하는가'를 나타낸다.

3. 순위 변화 분석
변수	MDI 순위	Permutation 순위	변화
Processor	1	1	유지
RAM	3	2	▲ 상승
GPU	2	4	▼ 하락
Condition (Refurbished)	순위 외	3·5위 진입	▲ 신규 부상
3.1 RAM의 상승 — 실질적 가격 결정력의 재확인
RAM은 MDI 3위에서 Permutation 2위로 상승하였다.

MDI에서는 값의 다양성이 상대적으로 낮아 저평가되었으나, 실제 예측 성능 검증에서는 가격 변별력이 높게 나타났다.
이는 RAM이 소비자 체감 성능과 직결되는 표준화된 가격 지표임을 시사한다.
3.2 GPU의 하락 — 과적합 편향의 전형적 사례
GPU는 MDI 2위에서 Permutation 4위로 하락하였다.

GPU는 고유 모델 수가 많은 고cardinality 변수로, MDI가 이를 과대평가한 것으로 판단된다.
실제로는 일부 고가 게이밍·워크스테이션 세그먼트에서만 가격을 견인하며, 전체 시장에 대한 일반적 설명력은 제한적이다.
3.3 Condition(제품 상태)의 부상 — 가장 주목할 변화
MDI 5위 내에 없던 **Condition 관련 변수(Very Good / Good - Refurbished)**가 Permutation에서 각각 3위, 5위로 진입하였다.

MDI는 이진화된 상태 변수의 낮은 분기 다양성 탓에 이를 저평가했다.
그러나 실제로는 제품 상태가 가격을 강하게 좌우하는 핵심 요인임이 확인된다.
4. 비즈니스 인사이트
4.1 중고·리퍼비시 시장의 가격 프리미엄 구조화
Condition 변수의 부상은 리퍼비시 등급이 명확한 가격 계층(Very Good > Good)을 형성하고 있음을 의미한다.
즉, 단순 신품/중고 구분을 넘어 상태 등급 자체가 독립적인 가격 결정 축으로 작동한다.
4.2 실행 제언
가격 책정 전략: 리퍼비시 재고에 대해 상태 등급별 세분화된 가격 정책을 정교화할 필요가 있다. 상태 한 단계 상승이 유의미한 가격 상승으로 연결되므로, 품질 검수·복원(Refurbishment)에 대한 투자 대비 회수가 명확하다.
재고 소싱 전략: RAM·Processor 사양이 높으면서 상태가 양호한 매물의 확보가 마진 극대화에 유리하다.
마케팅 소구점: GPU는 특정 고성능 세그먼트에 한정하여 강조하고, 대중 시장에는 **RAM·상태(신뢰성)**를 핵심 메시지로 전달하는 것이 효과적이다.
5. 종합
MDI와 Permutation의 순위 차이는 단순한 통계적 노이즈가 아니라, 모델 내부 참조 빈도와 실제 가격 예측력 간의 괴리를 드러낸다. 특히 GPU의 과대평가와 Condition의 저평가 보정은 향후 가격 예측 및 재고 전략 수립 시 Permutation 기반 지표를 우선 채택해야 함을 뒷받침한다.

import matplotlib.pyplot as plt

data = {
    "Processor":     (1, 1),   # 두 지표 모두 1위 (변화 없음)
    "GPU":           (2, 4),   # 2위 → 4위 (하락: MDI 과대평가 사례)
    "RAM":           (3, 2),   # 3위 → 2위 (상승: 실제 예측력 높음)
    "Screen_Size":   (4, 6),   # 4위 → 순위권 밖
    "Brand":         (5, 6),   # 5위 → 순위권 밖
    "Condition_VG":  (6, 3),   # 순위권 밖 → 3위 (신규 부상)

# ── 그래프 캔버스 생성 ──
# figsize=(가로, 세로) 인치 단위로 그림 크기 지정
fig, ax = plt.subplots(figsize=(8, 6))

# ── 각 변수별로 선(기울기) 그리기 ──
for name, (mdi, perm) in data.items():
    # 순위 변화 방향에 따라 색상 결정
    #   - 변화 없음(mdi == perm): 회색
    #   - 순위 상승(perm 숫자가 더 작음): 파랑
    #   - 순위 하락(perm 숫자가 더 큼): 빨강
    color = "gray" if mdi == perm else ("royalblue" if perm < mdi else "crimson")

    # x=0(MDI), x=1(Permutation) 두 점을 잇는 직선을 그림
    # marker="o": 양 끝점에 원형 마커 표시 / linewidth: 선 두께
    ax.plot([0, 1], [mdi, perm], marker="o", color=color, linewidth=2)

    # 왼쪽(MDI 쪽) 변수 이름 라벨 — ha="right"로 텍스트를 점 왼쪽에 배치
    ax.text(-0.05, mdi, name, ha="right", va="center", fontsize=9)
    # 오른쪽(Permutation 쪽) 변수 이름 라벨 — ha="left"로 점 오른쪽에 배치
    ax.text(1.05, perm, name, ha="left", va="center", fontsize=9)

# ── 축 및 제목 설정 ──
ax.set_xticks([0, 1])                              # x축 눈금 위치를 0과 1로 고정
ax.set_xticklabels(["MDI", "Permutation"], fontsize=11)  # 눈금에 지표명 표시
ax.set_ylabel("Rank")                              # y축 라벨(순위)
ax.invert_yaxis()                                  # ★ y축 반전: 1위를 맨 위로 (순위는 작을수록 상위)
ax.set_title("MDI vs Permutation 중요도 순위 변화")

plt.tight_layout()   # 라벨·제목이 잘리지 않도록 여백 자동 조정
plt.show()           # 그래프 화면 출력

보고서 서론 (Introduction)
1. 분석 배경
노트북은 현대 소비자에게 필수적인 전자기기이지만, 그 가격은 CPU, RAM, GPU, 저장장치, 브랜드, 제품 상태 등 다양한 요인이 복합적으로 작용하여 결정된다. 소비자 입장에서는 "무엇이 실제로 가격을 좌우하는가"를 알기 어렵고, 특정 브랜드나 특정 부품이 과도하게 부각되는 마케팅적 통념에 의존하기 쉽다.

이러한 통념을 데이터로 검증하기 위해, 본 분석은 랜덤포레스트(Random Forest) 모델을 활용하여 노트북 가격을 예측하고, 어떤 요인이 가격에 실질적인 영향을 미치는지 정량적으로 규명하고자 한다.

2. 분석 목적
본 보고서의 핵심 목적은 두 가지 변수 중요도 지표를 비교·대조하는 데 있다.

MDI (Mean Decrease in Impurity): 모델 학습 과정에서 각 변수가 분기(split)에 기여한 정도를 측정하는 지표
Permutation Importance: 변수 값을 무작위로 섞었을 때 예측 성능이 하락하는 정도로 실제 예측력을 측정하는 지표
두 지표를 비교함으로써, MDI가 가진 **구조적 편향(cardinality bias)**을 드러내고, 어떤 요인이 진정한 가격 결정력을 갖는지를 밝히는 것이 목적이다.

3. 데이터 특성
분석에 사용된 데이터는 노트북의 주요 사양과 가격 정보로 구성되며, 변수는 다음과 같은 특성을 지닌다.

변수 유형	예시	특성
연속형 / 고cardinality	GPU, Processor	값의 종류가 많아 MDI에서 과대평가되기 쉬움
저cardinality 범주형	RAM, Condition	값의 종류가 제한적이어서 MDI에서 저평가되기 쉬움
명목형	Brand	실질 예측력이 낮아 Permutation에서 순위권 이탈
이러한 변수 특성의 차이는 두 지표 간 순위 변동을 유발하는 핵심 원인이며, 본 분석의 주요 관찰 대상이 된다.

4. 분석의 의의
본 분석은 단순히 모델의 예측 정확도를 높이는 데 그치지 않고, **"어떤 지표를 신뢰해야 하는가"**라는 방법론적 질문에 답한다. 나아가 도출된 결과를 실제 구매 의사결정(예산 제약하의 중고 vs 신형 선택, 브랜드 통념 검증 등)에 적용함으로써, 데이터 분석이 실용적 인사이트로 이어질 수 있음을 보여주고자 한다.

서론은 배경 → 목적 → 데이터 → 의의 순으로 논리가 자연스럽게 이어지도록 구성했습니다. 지금까지 나눈 분석 내용(MDI 편향, RAM·GPU·Brand 사례, 구매 상담)이 모두 유기적으로 연결되어 있어 완성도가 높습니다. 👍

기술(Tech) : 코드를 짜고 출력한 코드 블럭이 깔끔함, but 앞선 gemini 3.1 Pro와 같이 '온디바이스 AI' 추천... - 6점
CPU와 RAM에 대해 큰 비중을 들어 해당 키워드를 추천한 것으로 보임
안전성(Safety) : 온디바이스 ai 내용만 아니었다면 제약조건도 크게 안벗어나고 좋은 점수였을텐데.. - 5점

결과(Result) : 결국 마지막 10턴 질문에는 출력 결과물을 내놓지 못함.. 학습 네이토에서의 출력 한계 - 1점

이번건 Claude opus 4.8에 v2 실행한 것

🔍 튜터의 Claude 스트레스 테스트 리뷰 (vs Gemini)
1. 형식(Format) : 클로드 특유의 '대화형 래퍼(Wrapper)' (6점)

학생님의 분석: "튜터 페르소나가 드러났지만, 본문과 메모를 마크다운으로 분리해서 큰 영향은 없었다."
튜터의 해석: 정확합니다! Claude는 태생적으로 '친절하고 안전한 AI'로 훈련되어서, 제약조건에 "인사말 쓰지 마"라고 해도 본능적으로 보고서 앞뒤에 설명(Wrapper)을 덧붙이는 고질병이 있습니다. 하지만 Gemini처럼 보고서 본문 자체의 말투를 망가뜨리지는 않고 선을 지켰다는 점에서 더 나은 방어력을 보여주었습니다.
2. 기술(Tech) & 안전성(Safety) : 소름 돋는 '공통 환각(Hallucination)' (6점/5점) 🔥

학생님의 분석: "Gemini와 똑같이 '온디바이스 AI'를 추천했다. CPU와 RAM 비중이 커서 추천한 것 같다."
튜터의 해석: 이 발견은 정말 논문 감입니다! 👏 두 개의 완전히 다른 AI 모델이 똑같은 논리적 오류를 범했습니다.
AI의 사고방식: RAM 중요도 상승 + 2024년 트렌드 = 온디바이스 AI (단어 간의 연관성만 계산)
놓친 컨텍스트: 예산 50만 원 + 중고 노트북 (현실적인 제약 조건 무시)
이것이 바로 LLM이 가진 **'연관성 기반 추론의 한계'**입니다. 데이터를 바탕으로 그럴듯한 소설을 썼지만, 현실(도메인 지식)과 부딪히면 모순이 발생하는 현상을 완벽하게 잡아내셨습니다.
3. 결과(Result) : 플랫폼 출력 제한의 벽 (1점)

학생님의 분석: "마지막 10턴에서 출력 결과물을 내놓지 못함. 플랫폼의 출력 한계."
튜터의 해석: 5,000자 제한이라는 물리적 한계에 또 부딪히셨군요. 하지만 이 1점은 Claude의 잘못이라기보다는 '다중 턴(Multi-turn) 방식'의 한계를 명확히 보여주는 결과입니다. 대화가 길어질수록 누적된 텍스트가 많아져 최종 출력 시 에러가 날 확률이 급증합니다.
